# Spark-Skills

Skills d'agent pour TeamSpark.

## spark-gen

Génère un livrable TeamSpark (`project.md`, vidéo, logo, visuels) à partir d'un dépôt.

Installation :

```
npx skills add jm-parent/Spark-Skills --skill spark-gen -g
```

Utilisation : `/spark-gen` dans l'agent, répondre à la durée voulue (20 à 120 s, 20 par défaut), puis envoyer le dossier `_spotlight/<slug>/` généré à Jean-Marie PARENT.
